# YAPPY

YAPPY is an offline Grade 12 study companion for Mathematics, Physics, Chemistry, Biology, English, Computer Science, Economics, History, and Geography.

Open `index.html` in any modern browser. It needs no install, account, API key, or internet connection.

## Features

- Subject-specific prompts and formula deck
- Structured answers with method, answer check, and next step
- Local Grade 12 concept library across nine subjects
- Browser-saved chat history and exported study sessions

YAPPY uses a curated local response engine. Check key facts and calculations with class materials.
